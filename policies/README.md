# Warranty Policy Files

The active application policy is `warranty_policies.json`, which contains the
category-specific rule set consumed by the application.

The three standalone policy files provide explicit SRS submission artifacts:

- `electronics.json`
- `home_appliances.json`
- `default.json`

They express coverage, exclusions, reporting deadlines, repair conditions,
authorized-service requirements, replacement conditions, grace periods,
mandatory documents, hard-fail rules, warning rules, and manual-review rules.
